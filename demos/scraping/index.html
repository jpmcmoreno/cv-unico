Cada medio organiza su página de una forma distinta. El trabajo está en encontrar los selectores que sacan el titular, el enlace y la fecha de cada nota. Aquí puedes escribirlos, romperlos y ver el resultado al instante.

Cómo funciona

    
El navegador analiza el HTML de ejemplo y aplica tus selectores con querySelectorAll, igual que Scrapy aplica response.css() sobre la respuesta de un servidor. El bloque de código muestra el spider equivalente con los selectores que tengas escritos en ese momento.

    
Dos diferencias con un scraper real: esta demo lee una página guardada en lugar de pedirla por la red (un navegador no puede leer otros sitios por seguridad), y ::text aquí devuelve todo el texto del elemento, mientras que en Scrapy devuelve solo el texto directo. El código de la empresa no se publica; esto muestra la técnica.
